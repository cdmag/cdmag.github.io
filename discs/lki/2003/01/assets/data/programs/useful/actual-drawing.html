Среди множества программ для веб-дизайна Actual Drawing уверенно выделяется визуальным подходом. По идее, чтобы работать с этим редактором, знать HTML вообще необязательно. Редактор дает множество графических возможностей, работает с тенями, анимациями и т.п. И даже сам загружает созданную страницу на ваш сервер.
