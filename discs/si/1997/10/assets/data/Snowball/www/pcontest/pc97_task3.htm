Задание N3
 

Multithreading
 

Дано:

Следующий game loop:

 

Примечания и пояснения к схеме:

0. Ожидание флажка таймера, устанавливаемого через равные промежутки времени
1. В данном блоке происходит изменение координат объектов, создание новых и уничтожение ненужных объектов
2. В данном блоке происходит передача состояния объектов в систему рендеринга
3. Система рендеринга: используется двойная буферизация, то есть пока отсчитывается текущий кадр доступен предыдущий кадр
4. Отрисовка готового кадра с использованием результата блока 3 и наложение на него интерфейсных элементов (курсора, рамок и т.д.)

          Замечания:

  1. Передача данных о состоянии объектов (2) не может происходить одновременно с блоком 1 и с блоком 3
  2. Блок 4 копирует данные из того буфера блока 3, в котором отрисовка завершена полностью.
 

Необходимо:

Предложить способ распараллеливания данного цикла на несколько независимых threads в виде схемы с указанием всех необходимых для этого семафоров, таймеров и ключевых частей кода.
