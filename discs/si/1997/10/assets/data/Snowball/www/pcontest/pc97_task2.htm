Задание N2
 

Распаковка
 
Дано:

Фрагмент данных, запакованный следующим образом: сначала копируется некоторое количество байтов из начала, затем определенное количество раз повторяется середина, и затем копируются оставшиеся байты. Осуществить реализацию следующего класса:

class packedBuffer
{
public:
    packedBuffer(
    BYTE* src             // адрес массива данных
    int len                   // размер массива
    int intro_len        // размер начала
    int loop_len        // размер зацикленной части
    int loop_cnt          // необходимое количество повторений зацикленной части
    );
    int getNextBlock(void* dst, int size);
}

 
 
Необходимо:

Написать на C++ реализацию приведенного выше класса, при этом функция

int packedBuffer::getNextBlock(void* dst, int size)

должна копировать следующие size байт из запакованного массива в память по адресу dst и возвращать количество реально скопированных байтов или ноль, если копировать больше нечего.
 

Примечание:

Типичное использование данной функции:

pBuff=new packedBuffer(packedData, packedDataSize, introSize, loopedSize, loopNumber);
dst=new BYTE[bufSz];
while((unpackedSz=pBuff->getNextBlock(dst,bufSz))!=0)
    fwrite(dst,unpackedSz,1,fileHandle);
