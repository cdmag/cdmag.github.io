Задание N4
 

Изменяющиеся треугольники
 
Дано:

Две структуры данных

struct Triangle
{
    Normal        norm;    
    Lighting        lighting;
}

struct Point
{
    int    z;
    Normal    norm;
}
Примечание:

координаты x, y не входят в данную структуру, поскольку они однозначно определяются местом данной точки в массиве вершин

Следующие константы:

TR_WIDTH ширина треугольника
TR_HEIGHT высота треугольника
TR_DX количество треугольников по горизонтали
TR_DY количество треугольников по вертикали

Два массива данных:

Point points[(TR_DY+1)*(TR_DX/2+1)];
Triangle triangles[TR_DY*TR_DX];

расположенных по следующей схеме:
 

 
 

Между описанными выше структурами данных существуют следующие зависимости:

Point::z Набор высот в вершинах сетки. Исходная информация.
Triangle::norm Нормаль в треугольнике. Получается из трехмерных координат его вершин при помощи следующей функции:
    Normal& normalFromPoints(int* x, int* y, int* z).
    (x,y,z-массивы трех соответствующих координат)
Point::norm Нормаль в вершине. Получается из нормалей всех прилегающих треугольников при помощи следующей функции:
    Normal& normalFromTriangles(Normal& n1,Normal& n2,
                     Normal& n3,Normal& n4,Normal& n5,Normal& n6)
Triangle::lighting Некий параметр освещенности в треугольнике. Получается из нормалей в вершинах треугольника при помощи следующей функции:
Lighting& lightingFromPoints(Normal& n1,Normal& n2,
                                            Normal& n3)

 
 

Требуется:

Написать реализацию следующей функции

void recalculateMesh(int* mc, int no);

На вход данной функции передается массив индексов измененных вершин. Новая z-координата уже занесена в эти вершины. Данная функция должна учитывать все передаваемые изменения и в соответствии с ними и описанными выше зависимостями пересчитывать измененные вершины и треугольники. При этом накладывается дополнительное условие: каждый треугольник и вершина не должны пересчитываться более чем один раз, а неизмененные вершины и треугольники не должны пересчитываться вообще.

Примечание: считается, что все получающиеся в процессе изменений треугольники находятся внутри сетки.
