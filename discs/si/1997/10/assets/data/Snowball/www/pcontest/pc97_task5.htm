Задание N5
 

Обработка списка
 

Дано:

Следующие структуры данных:

class ListHolder
{
    ListItem* head;
public:
    ListHolder();
    ~ListHolder();
}

class ListItem
{
    ListItem* prev;
    ListItem* next;
public:
    ListItem ();
    ~ListItem ();

    int getEmbeddedNumber();
    void idle();
   BOOL isItONE(int criteria);
  
    friend class ListHolder;

}

Класс ListHolder представляет из себя некий объект в котором находится указатель на начало двунаправленного списка (ListItem).

Класс ListItem является обычным двунаправленным списком (prev – указатель на предыдущий элемент, NULL – если это последний элемент, next – указатель на следующий элемент, NULL – если это первый элемент)
 

 
Необходимо:
  1. Реализовать механизм ‘forEachMember’ в классе ListHolder, позволяющий «пробегаться» по всем элементам списка и для каждого из этих элементов выполнить определенное действие, которое может быть представлено как в данном, так и в дочернем классе.
  2. Реализовать дочерний класс со следующими функциями:

class ChildListHolder: public ListHolder
{
public:

    int getListSum();
    ListItem* getRightONE(int criteria);
    void idle();
};

  1. int ChildListHolder::getListSum()
    Данная функция должна возвращать сумму, полученную от всех элементов списка ListItem (при помощи функции
    int ListItem::getEmbeddedNumber())
  2. ListItem* ChildListHolder::getRightONE(int criteria)
    Данная функция должна возвращать указатель на первый из тех элементов списка, которые вернули ‘TRUE’ при обращении к функции
    BOOL ListItem::isItONE(int criteria)
  3. void ChildListHolder::idle()
    Данная функция должна вызывать функцию void ListItem::idle() для каждого из элементов списка.
